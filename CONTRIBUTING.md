# Contributing

Contributions are welcome when they improve educational clarity, correctness, or practical value.

## Contribution guidelines

- Keep material technically accurate and grounded in official documentation.
- Prefer original explanations over copied content.
- Add runnable examples or lab steps where possible.
- Document assumptions and prerequisites clearly.
- Keep discussions focused on platform engineering learning outcomes.

## Suggested improvements

- Add missing labs or troubleshooting notes
- Improve diagrams and architecture explanations
- Correct inaccuracies in module content
- Add new projects or mini labs for beginner-to-intermediate learners

## Pull request expectations

- Explain the topic and the learning value of the change
- Include validation steps when adding commands or scripts
- Keep scope focused and easy to review
- Update relevant navigation pages if structure changes

## Style conventions

- Use Markdown with clear headings
- Prefer concise explanations with practical examples
- Use relative links within the repository
- Keep command snippets executable and safe

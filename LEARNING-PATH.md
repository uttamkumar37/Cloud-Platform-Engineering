# Learning Path

## Stage 1: Build the base

1. Understand network primitives and the OSI/TCP-IP model
2. Learn Linux administration essentials and shell workflows
3. Manage Git flows, automation, and scripting
4. Understand core cloud concepts, IaaS/PaaS/SaaS, and organizational boundaries

## Stage 2: Run modern workloads

1. Package and run applications with containers
2. Learn Kubernetes objects, networking, and workloads
3. Study OpenShift operational patterns and enterprise platform needs
4. Use AWS to see how public cloud services map to real architectures

## Stage 3: Automate and standardize

1. Provision and manage infrastructure with Terraform
2. Automate configuration with Ansible and idempotent practices
3. Build robust CI/CD workflows and release automation
4. Apply GitOps patterns to reconcile platform state

## Stage 4: Operate at scale

1. Implement observability and telemetry
2. Create alerting, dashboards, and incident workflows
3. Understand cloud security, zero trust, and policy enforcement
4. Learn operational excellence through SRE and service reliability

## Stage 5: Platform engineering maturity

1. Design internal developer platforms
2. Balance developer experience with governance
3. Model cost, reliability, and environment lifecycle management
4. Build a systems-thinking approach to team and platform operations

## Suggested three-month schedule

- Month 1: modules 01-05
- Month 2: modules 06-12
- Month 3: modules 13-18 plus project work

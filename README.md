# Cloud & Platform Engineering Learning Academy

This repository is a practical learning path for developers who want to move from backend engineering into cloud, platform, Kubernetes, DevOps, SRE, and production engineering roles.

The curriculum is designed for engineers with a Java, Go, or backend development background and a working understanding of Git, REST APIs, and container concepts. It starts with fundamentals and builds toward production-grade system design, cloud operations, and platform engineering.

## What this repository includes

- Structured learning roadmap from fundamentals to advanced platform engineering
- Original theory notes in Markdown
- Hands-on labs and examples using Linux, Docker/Podman, Kubernetes, AWS, Terraform, GitHub Actions, and GitOps
- Interview preparation, troubleshooting guides, and certification-focused study notes
- Real-world project tracks for cloud-native application delivery

## Learning outcomes

By the end of the path, learners should be able to:

- Design and troubleshoot basic to advanced cloud-native systems
- Manage Linux, networking, containers, and Kubernetes workloads
- Work confidently with AWS, Terraform, CI/CD, GitOps, and observability tools
- Understand the design decisions behind reliability, security, and scalability
- Prepare for platform engineering, SRE, and cloud interview discussions

## Recommended learning path

Start with the fundamentals:

1. Computer networking
2. Linux administration
3. Git and scripting
4. Cloud fundamentals
5. Containers and OCI
6. Kubernetes and platform primitives
7. AWS and infrastructure design
8. Terraform and automation
9. CI/CD and GitOps
10. Observability, reliability, and security

See [LEARNING-PATH.md](./LEARNING-PATH.md) for a more detailed path.

## Required local setup

A modern Linux or macOS environment is ideal. For Windows users, WSL2 is recommended. See:

- [docs/setup-linux.md](./docs/setup-linux.md)
- [docs/setup-windows-wsl.md](./docs/setup-windows-wsl.md)

## Suggested toolchain

- Git and GitHub
- Bash and Python
- Docker or Podman
- kubectl and a local cluster such as kind or k3d
- Terraform
- AWS CLI and a sandbox account (if available)
- Prometheus and Grafana for observability experiments

## Learning philosophy

This repository emphasizes:

- fundamentals before abstractions
- production reasoning over memorization
- repeatable labs and troubleshooting over theoretical-only study
- understanding the why behind architecture decisions
- secure, observable, and resilient platform design

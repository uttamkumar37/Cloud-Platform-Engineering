# Cloud & Platform Engineering Roadmap

This roadmap is structured to take a backend engineer from software delivery fundamentals to platform and cloud engineering fluency.

## Phase 1: Foundations

- Computer networking
- Linux administration
- Git and scripting
- Cloud fundamentals

## Phase 2: Runtime and platform primaries

- Containers and OCI
- Kubernetes core concepts
- OpenShift and enterprise platform patterns
- AWS cloud architecture

## Phase 3: Delivery and automation

- Terraform and infrastructure as code
- Configuration management
- CI/CD pipelines
- GitOps and progressive delivery

## Phase 4: Reliability and operations

- Observability and telemetry
- SRE and reliability engineering
- Cloud security and identity
- Cost and governance

## Phase 5: Advanced platform engineering

- Internal developer platforms
- Multi-environment delivery patterns
- Policy, governance, and compliance
- Service ownership and platform operating model

## Recommended cadence

- 2 to 3 hours per week: theory and notes
- 2 to 4 hours per week: labs and tutorials
- 1 hour per week: interview or exam review
- 1 real project milestone every 2 to 4 weeks

## Outcome targets

By the end of the roadmap, learners should be able to:

- troubleshoot complex system issues across layers
- explain how cloud resources are connected and secured
- deploy and operate Kubernetes applications
- write secure IaC and deployment automation
- build production-ready observability and incident response workflows

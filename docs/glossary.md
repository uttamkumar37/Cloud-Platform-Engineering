# Glossary

## Cloud
The delivery of computing resources over the network, typically as on-demand services.

## Platform engineering
The practice of building internal platforms and developer workflows that standardize delivery, security, and operations.

## Container
A lightweight, isolated runtime that packages application code and dependencies.

## Kubernetes
A portable orchestration platform for deploying and scaling containerized workloads.

## SRE
Site reliability engineering: the practice of combining software engineering with operational reliability.

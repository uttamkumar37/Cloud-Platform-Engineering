# Prerequisites

This path assumes a working developer environment and a willingness to learn through hands-on practice.

Recommended prerequisites:

- Basic understanding of OOP or backend programming
- Experience with Java, Go, or another backend language
- Familiarity with REST APIs and Git
- Comfort with command-line workflows

Strongly recommended tools:

- GitHub account
- VS Code or another IDE
- Linux/Mac terminal or WSL2 on Windows
- Docker or Podman
- kubectl

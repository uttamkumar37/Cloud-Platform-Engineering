# Module 01: Computer Networking

## Overview

This module covers the core concepts, operational thinking, and practical patterns behind ip addressing, subnetting, routing, dns, http/tls, load balancing, nat, and cloud networking..

## Why this topic matters

Computer Networking is one of the foundational disciplines behind modern cloud and platform engineering. Understanding it helps engineers design systems that are resilient, observable, secure, and easy to operate.

## Prerequisites

- A working terminal and Git environment
- Prior experience with backend development or DevOps basics
- Comfort with reading documentation and using CLI tools

## Learning objectives

- Understand the core architecture and terminology of computer networking
- Learn the most important components, failure modes, and trade-offs
- Practice production-style debugging and validation
- Apply the relevant concepts in labs and real deployment scenarios

## Curriculum

- Core concepts and mental models
- Common architecture patterns
- Operational validation and troubleshooting
- Production design trade-offs and security considerations

## Estimated learning effort

4 to 8 hours of guided study plus 2 to 6 hours of hands-on labs, depending on prior experience.

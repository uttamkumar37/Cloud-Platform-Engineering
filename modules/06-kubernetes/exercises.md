# Exercises: Kubernetes

## Exercise 1: Understand the model

Explain the primary components, responsibilities, and failure modes of kubernetes.

Acceptance criteria:
- Identify at least 5 core concepts
- Explain one operational failure mode and one recovery path

## Exercise 2: Build a proof of concept

Create a minimal working example in a local environment and document the setup steps.

Acceptance criteria:
- The environment runs successfully
- The output is validated with a command or health check

## Exercise 3: Production reflection

Compare a local setup with a production-ready design and identify key differences.

Acceptance criteria:
- Describe security and reliability changes required at scale
- Provide at least three trade-off observations

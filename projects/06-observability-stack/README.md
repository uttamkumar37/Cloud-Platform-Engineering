# 06 Observability Stack

## Goal

Deploy a metrics and logs pipeline using Prometheus, Grafana, and Loki.

## Learning outcomes

- Understand architecture and deployment trade-offs
- Use real tooling to validate a system end-to-end
- Capture operational evidence and improvements

## Suggested phases

1. Design the system and define requirements
2. Build the application or infrastructure needed
3. Deploy, validate, and troubleshoot the environment
4. Document operational decisions and follow-up actions
